# قاعدة بيانات صوتك+

قاعدة الإنتاج تُدار مباشرة عبر Supabase migrations والسياسات المطبقة، ولا يوجد في هذا المستودع ملف bootstrap قابل للتنفيذ على قاعدة الإنتاج.

## قواعد الأمان
- لا تضع `SUPABASE_SERVICE_ROLE_KEY` أو أي Secret في الواجهة أو المستودع.
- مفتاح Supabase Publishable المرسل للمتصفح ليس سرًا؛ الحماية الفعلية تعتمد على RLS وصلاحيات الوظائف.
- بيانات النماذج الخاصة لا تُقرأ من `anon` أو من مستخدم عادي؛ الوصول الإداري يتطلب حساب إدارة فعّالًا وAAL2/MFA.
- المواد المحمية لا تُخزن كملفات عامة، وتُعاد فقط من Edge Function بعد تحقق الاستحقاق.
- النماذج العامة تمر عبر `soutak-public-submit` مع تحقق من المصدر، حدود حجم، تحقق من الحقول، honeypot وحدود طلبات ذرية على الخادم.
- أي تغيير في المخطط يجب أن يُنفذ كمهاجرة صغيرة قابلة للمراجعة ثم يُتبع بفحص Supabase Security Advisor.

لا تعِد إنشاء المخطط من ملفات قديمة أو نسخ من سجل Git؛ مصدر الحقيقة هو مخطط Supabase الحالي والمهاجرات المطبقة عليه.
