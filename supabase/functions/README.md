# Supabase Edge Functions — صوتك+

الدوال النشطة في الإنتاج هي فقط ما يلي:

## `soutak-public-submit`
نقطة الإدخال العامة للنشرة والتواصل والخدمات والتعاون. تعمل بدون JWT لأن الزائر قد يكون غير مسجل، لكنها تطبق تحققًا مخصصًا: قائمة مصادر مسموحة، POST/OPTIONS فقط، حد لحجم الطلب، تحقق من الحقول والقيم، honeypot، وحدود طلبات ذرية على الخادم باستخدام hashes غير قابلة لإرجاع البريد/IP الخام.

## `soutak-reward`
دالة المواد المحمية. تتطلب JWT صالحًا، تقبل الموارد الثلاثة المعروفة فقط، وتستخدم تحديات أحادية الاستخدام واستحقاقات محفوظة في الخادم. المحتوى المحمي لا يُعاد إلا بعد تحقق الاستحقاق.

## أسرار الخادم
`SUPABASE_SERVICE_ROLE_KEY` وأي Secret آخر يبقى داخل Supabase Edge Functions/Secrets فقط ولا يوضع في JavaScript العام أو Vercel runtime endpoint أو المستودع.

أي دالة قديمة غير مستخدمة يجب ألا تبقى كمصدر قابل للنشر حتى لا يتم إرجاع إعداد أضعف بالخطأ.
