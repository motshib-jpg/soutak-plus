# صوتك+ — SoutakPlus

موقع عربي RTL لصنّاع المحتوى، منشور على الإنتاج عبر Vercel:

`https://soutak-plus.vercel.app/`

## الحالة الحالية
- 20 مقالًا عربيًا ثابتًا ومفتوحًا للقراءة دون تسجيل أو دفع.
- صفحات المقالات HTML مستقلة، قابلة للزحف والمشاركة، ولا تعتمد على Supabase لعرض المحتوى.
- مكتبة المقالات تحتوي القائمة كاملة داخل HTML ولا تحتاج قاعدة البيانات لاكتشاف المقالات.
- مختبر محتوى محلي داخل `content.html` يقدم أدوات عملية دون حفظ أو إرسال مدخلات المستخدم.
- خدمات وتواصل ورعاية عبر نماذج تمر إلى Edge Function خادمية مع ضوابط منع الإساءة.
- لوحة إدارة منفصلة ومحميّة بـ MFA/AAL2.
- PWA + Service Worker مع تنظيف تلقائي للكاش القديم.
- CSP/HSTS ورؤوس أمان وفحوص CI دائمة.
- `robots.txt` + `sitemap.xml` + `ads.txt` + تحقق Search Console.

## الربح
النموذج الحالي هو Google AdSense على صفحات المحتوى المؤهلة فقط، مع إمكانية التعاون/الرعاية المباشرة بصورة منفصلة وواضحة.

لا توجد اشتراكات أو Checkout أو دفع لقراءة المقالات. نظام Rewarded Ads القديم غير موجود في فرع الإنتاج `main`، والنسخة التاريخية محفوظة فقط في `archive/rewarded-ads-future` إذا تقرر تطويرها مستقبلًا.

## Supabase
Supabase مستخدم فقط عندما توجد حاجة خادمية فعلية، مثل استقبال النماذج وبيانات الإدارة. صفحات القراءة العامة لا تحمل Supabase SDK أو عميل قاعدة البيانات.

- المشروع: `lauhvvrjqiqaxfiwswqw`
- RLS مفعّل على جداول الإنتاج العامة.
- لا يوجد Service Role Key في المتصفح.
- النماذج العامة تستخدم `soutak-public-submit` بدل كتابة مباشرة من العميل.

## النشر
الفرع `main` هو مصدر الإنتاج. أي Push يمر عبر `.github/workflows/import-site.yml` ثم يلتقطه ربط GitHub في Vercel للنشر التلقائي.

لا يوجد Build للموقع؛ هو Static HTML/CSS/JS مع دالة Vercel صغيرة لتهيئة وقت التشغيل.

## الجودة
شغّل:

```bash
python3 QA_CHECK.py
```

الفحص ديناميكي: يكتشف عدد المقالات تلقائيًا ويتأكد من sitemap والـMetadata وSchema والروابط وJavaScript ونطاق AdSense وأمان الإدارة والنماذج، ويمنع عودة الملفات أو تبعيات Supabase غير الضرورية إلى صفحات القراءة.

## قاعدة التطوير
لا تضف صفحات أو ميزات لمجرد زيادة العدد. أي محتوى جديد يجب أن يضيف فائدة قابلة للاستخدام أو التحقق، وأي اعتماد JavaScript جديد يجب أن تكون له حاجة فعلية في الصفحة التي تحمله.
